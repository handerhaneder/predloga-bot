# 🤖 Бот «Предлога»

Телеграм-бот для сбора запросов на совместный блог.

## 📁 Структура

```
predloga_bot/
├── bot.py          # Основной файл бота
├── config.py       # Конфигурация (токен и ID создателя)
├── database.py     # База данных SQLite
├── requirements.txt
└── README.md
```

## 🚀 Запуск

### 1. Установить зависимости
```bash
pip install -r requirements.txt
```

### 2. Настроить config.py

Открой `config.py` и замени:
- `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather)
- `CREATOR_ID` — твой Telegram ID (узнать у [@userinfobot](https://t.me/userinfobot))

```python
BOT_TOKEN = "1234567890:AAF..."
CREATOR_ID = 987654321
```

### 3. Запустить бота
```bash
python bot.py
```

---

## ⚙️ Функционал

| Кнопка | Кто видит | Что делает |
|---|---|---|
| 📨 Послать запрос на совместный блог | Все пользователи | Сохраняет контакт и уведомляет создателя |
| 📋 Посмотреть запросы | Только создатель | Показывает список всех заявок с контактами |

## 📌 Как работает

1. Пользователь нажимает **«Послать запрос»**
2. Бот сохраняет его имя, @username и ID в базу данных
3. Создатель получает мгновенное уведомление с кнопкой «Написать напрямую»
4. Создатель может в любой момент посмотреть все запросы командой через кнопку **«Посмотреть запросы»**
